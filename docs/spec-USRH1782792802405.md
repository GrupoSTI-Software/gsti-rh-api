Invariante de fijeza: **como máximo un lugar fijo pactado activo por empleado**. Se garantiza en el servicio (al marcar uno como fijo se desmarcan los demás del mismo empleado), no con unique index (los soft-deleted lo romperían).

## 4. Contrato de API

Rutas en `start/routes/nom037_routes.ts`, bajo `middleware.auth()` + `middleware.businessScope()`:

```
GET    /api/nom037/telework-locations?employeeId=:id   200 lista de lugares activos del empleado
POST   /api/nom037/telework-locations                  201 crea lugar (gating Remote/Hybrid)
PUT    /api/nom037/telework-locations/:id              200 actualiza lugar
DELETE /api/nom037/telework-locations/:id              200 baja lógica
```

Respuestas en formato del repo `{ type, title, message, data }`. Errores con `code` del catálogo `TWL.*` (`app/constants/employee_telework_location_error_codes.ts`):

| Código | Situación | HTTP |
|---|---|---|
| `TWL.VAL.001` | Validación VineJS / input inválido | 400 |
| `TWL.VAL.GATING.001` | El empleado no es teletrabajador (modalidad Onsite) — key `solo-teletrabajadores` | 422 |
| `TWL.NF.EMP.001` | Empleado inexistente o fuera del tenant | 404 |
| `TWL.NF.LOC.001` | Lugar inexistente, borrado o fuera del tenant | 404 |
| `TWL.SYS.001` | Error no clasificado | 500 |

El gating y la pertenencia al tenant se validan en `EmployeeTeleworkLocationService` consultando el empleado dentro de `businessUnitScope`.
